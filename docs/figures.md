## 3. 公共交通步行接驳图表

### 3.1 地铁与公交平均接驳距离图

展示15个城市CityWalk目的地到周边地铁、公交站点的平均最短估算步行距离，单位为米。

各城市平均值仅根据成功获得有效路网路径的景点计算，同时保留有效景点数量，避免将计算失败记录作为0米处理。

### 3.2 交通—商业四象限图

横轴为城市平均地铁接驳距离，纵轴为平均商业POI数量。

以15个城市对应指标的中位数划分四象限，用于比较不同城市的交通接驳与商业服务匹配情况。

地铁距离越短表示估算接驳条件越好，商业POI数量越多表示商业设施越丰富。

### 3.3 交通—商业双优景点占比图

统计每个城市20个CityWalk目的地中，同时满足以下条件的景点比例：

- 地铁估算步行距离不超过500米。
- 周边500米内商业POI数量不少于47条。

该图用于比较不同城市同时具备两项条件的目的地分布情况。
