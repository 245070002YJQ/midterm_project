## 2. 商业设施分析图表

### 2.1 商业设施丰富度排名图

横轴为平均商业POI数量，纵轴为15个城市名称。

平均商业POI数量指各城市20个CityWalk目的地的500米缓冲区内商业设施总数的平均值。条形图按平均商业总数从高到低排序，用于直观对比不同城市核心景点的商业设施密集程度与供给规模。

### 2.2 商业业态多样性排名图

横轴为香农-威纳多样性指数，纵轴为15个城市名称。

香农指数基于高德三级细分小类标签（如中餐厅、便利店等）计算，用于表示各城市商业业态的混合度。条形图按多样性指数从高到低排序，指数越高表示该区域商业种类越丰富、结构越均衡。
## 3. 公共交通步行接驳图表

### 3.1 地铁与公交平均接驳距离图

展示15个城市CityWalk目的地到周边地铁、公交站点的平均最短估算步行距离，单位为米。

各城市平均值仅根据成功获得有效路网路径的景点计算，同时保留有效景点数量，避免将计算失败记录作为0米处理。

### 3.2 交通—商业四象限图

横轴为城市平均地铁接驳距离，纵轴为平均商业POI数量。

以15个城市对应指标的中位数划分四象限，用于比较不同城市的交通接驳与商业服务匹配情况。

地铁距离越短表示估算接驳条件越好，商业POI数量越多表示商业设施越丰富。

### 3.3 交通—商业双优景点占比图

统计每个城市20个CityWalk目的地中，同时满足以下条件的景点比例：

- 地铁估算步行距离不超过500米。
- 周边500米内商业POI数量不少于47条。

该图用于比较不同城市同时具备两项条件的目的地分布情况。

## 4. 绿化与综合评价图表
### 4.1 哪座城市最适合CityWalk？——基准情景下15个新一线城市综合排名
基准排名图：https://github.com/245070002YJQ/midterm_project/blob/main/docs/Chart1_Baseline_Ranking.png

**图表说明**：本图展示了基于步行连通性、商业服务、交通接驳与绿化条件四个维度等权重计算下的15个新一线城市CityWalk适宜性综合得分。
**核心结论**：宁波、青岛与重庆的综合得分位列前三，展现出极强的CityWalk优势；东莞、郑州等城市排名相对靠后。这说明这三座城市在“路网-商业-交通-绿化”的资源配置上达到了较好的均衡。

### 4.2 偏好改变会导致排名反转吗？——不同游逛偏好下的城市排名变化
不同群体偏好下的排名变化图：

**图表说明**：本图展示了在基准情景、自然偏好情景（重绿化）与购物偏好情景（重商业）下，15个城市的综合排名变化（纵轴为排名，1代表最优）。
**核心结论**：城市排名对权重设置高度敏感，发生了剧烈反转。在自然偏好下，重庆凭借极高的绿化均值跃居第一；而在购物偏好下，青岛凭借密集的商业设施位列榜首。这证明了不存在绝对的“最优CityWalk城市”，推荐结果高度依赖于漫步者的特定偏好。

### 4.3 城市内部存在怎样的空间权衡？——K-Means 聚类中心特征雷达图
K-Means图：

**图表说明**：本图展示了基于标准化后的四维指标，利用 K-Means 算法对所有城市网格进行无监督聚类后的中心特征。图中三条线分别代表三类典型的空间区域。
**核心结论**：聚类成功识别出“交通枢纽型”（交通接驳得分极高）、“商业核心型”（商业与路网密度极高）与“绿地休闲型”（绿化 NDVI 极高）三类区域。雷达图直观呈现了显著的“空间权衡（Spatial Trade-off）”现象，即城市内部极少存在完美的CityWalk空间，各区域往往在“商业便利”与“自然休闲”之间有所侧重。
