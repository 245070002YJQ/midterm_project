## 2. 商业设施分析
### 2.1 数据筛选

使用Python对高德地图采集的商业POI数据进行多重标签拆分（将以“|”分隔的复合业态还原为单一细分业态）、坐标缺失记录剔除及去重。仅保留与CityWalk高度相关的餐饮、购物、休闲三大类核心商业设施。高德GCJ-02坐标转换为WGS84，并在距离计算阶段统一转换为对应城市的UTM米制投影坐标系，用于后续500米缓冲区的空间匹配。

### 2.2 计算相关参数

| 参数 | 设置 |
| --- | --- |
| 商业服务范围（Buffer） | 500米 |
| 业态分类层级 | 高德三级细分小类 |
| 丰富度计算指标 | 缓冲区内的商业POI总数 |
| 多样性计算指标 | 香农-威纳指数 (Shannon-Wiener Index) |

商业业态多样性指数计算公式：

**H = - Σ (P_i * ln(P_i))**

其中，P_i 为第 i 种细分业态的 POI 数量占该范围内商业 POI 总数的比例。该指数用于衡量 500 米范围内商业设施的混合度与结构均衡性。
## 3. 公共交通步行接驳分析

### 3.1 数据筛选

使用Python对高德地图采集的CityWalk候选景点进行评分检查、类型筛选和名称去重，并通过AOI空间匹配限定研究范围。最终每个城市选取20个目的地，15个城市共300个景点。高德GCJ-02坐标转换为WGS84，并在距离计算阶段统一转换为对应城市的UTM米制投影坐标系。

### 3.2 关键计算参数

| 参数 | 设置 |
| --- | --- |
| 候选地铁及公交站点范围 | 800米 |
| 附近候选道路 | 10条 |
| 每个位置最多道路接入点 | 3个 |
| 最短路径算法 | Dijkstra |
| 距离计算权重 | 道路长度 |
| 估算步行速度 | 75米/分钟 |

估算总步行距离：

**总距离 = 景点接入距离 + OSM道路最短路径距离 + 站点接入距离**

估算步行时间：

**步行时间（分钟）= 总距离（米）/ 75**

无法获得有效Dijkstra路径时，保留失败状态，不将直线参考距离视为有效步行距离。

城市平均距离只使用成功计算出有效路网路径的景点。

### 3.3 交通与商业匹配标准

结合景点地铁接驳距离与周边500米范围内的商业POI数量进行分析。

交通—商业双优景点需要同时满足：

- 地铁估算步行距离不超过500米。
- 周边500米内商业POI数量不少于47条。

双优景点占比：

**双优景点占比 = 符合条件的景点数量 / 20 × 100%**

无有效地铁路径的景点不计入双优景点，但仍保留在每城20个景点的统计总数中。


## 4. 绿化环境指标 (NDVI) 提取方法

*   **数据源与时间窗口**：数据来源于 Sentinel-2 (COPERNICUS/S2_SR_HARMONIZED) 地表反射率数据。选取 2025 年夏季 (6月1日至8月31日) 影像，以捕捉植被生长最茂盛时期。
*   **云掩膜处理**：在 GEE 平台设定过滤条件，仅保留云量低于 25% 的影像，并利用 SCL (场景分类层) 波段进行云掩膜，剔除云层及阴影干扰，取时间序列中位数合成无云影像。
*   **计算公式**：通过计算近红外波段 (B8) 与红光波段 (B4) 的归一化差异，生成 NDVI 植被指数：
    $$
    NDVI = \frac{B8 - B4}{B8 + B4}
    $$
*   **空间聚合**：将 500m 网格图层上传至 GEE，利用 `reduceRegion` 函数，以 30m 空间分辨率对每个 500m 网格内的 NDVI 像元进行均值与标准差统计，导出包含 `grid_id`, `ndvi_mean`, `ndvi_std` 的指标，作为城市绿化环境的量化基础。

## 5. 综合评价与空间聚类方法

### 5.1 综合评价指标体系与标准化
*   基于研究问题三，构建了包含 **步行连通性、商业服务、交通接驳与绿化条件** 四个维度的评价体系。
*   为消除量纲影响，采用 **Z-score 标准化** 方法对15个城市的汇总数据进行全局标准化处理，以便后续进行多维度综合评分与聚类分析。

### 5.2 权重设置与情景分析
为探究不同游逛偏好对CityWalk综合适宜性评价结果的影响，本研究在基准模型的基础上，构建了三种差异化的权重情景：
1.  **基准情景 (Baseline)**：四个维度被赋予均等权重（各占 0.25），旨在评估城市综合宜居水平。
2.  **自然偏好情景 (Nature)**：针对偏好自然环境与安静氛围的群体，将绿化维度权重显著提升至 0.60，步行连通性设为 0.20，交通接驳与商业服务各占 0.10。
3.  **购物偏好情景 (Shopper)**：针对偏向消费与休闲娱乐的群体，将商业服务维度权重提升至 0.50，交通接驳占 0.20，步行连通性占 0.20，绿化条件占 0.10。
*   *目的*：通过对比三种情景下的城市排名变化，有效检验评价结果的稳健性与场景适用性。

### 5.3 K-Means 空间聚类
*   提取标准化后的四维指标，采用 **K-Means 算法** 对所有城市网格进行无监督聚类。
*   根据聚类中心的特征，将网格划分为“交通枢纽型”、“商业核心型”与“绿地休闲型”三类，以揭示各城市内部的空间分异规律。
