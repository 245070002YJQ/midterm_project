## 2. 商业设施分析
### 2.1 数据筛选

使用Python对高德地图采集的商业POI数据进行多重标签拆分（将以“|”分隔的复合业态还原为单一细分业态）、坐标缺失记录剔除及去重。仅保留与CityWalk高度相关的餐饮、购物、休闲三大类核心商业设施。高德GCJ-02坐标转换为WGS84，并在距离计算阶段统一转换为对应城市的UTM米制投影坐标系，用于后续500米缓冲区的空间匹配。

### 2.2 计算相关参数

| 参数 | 设置 |
| --- | --- |
| 商业服务范围（Buffer） | 500米 |
| 业态分类层级 | 高德三级细分小类 |
| 丰富度计算指标 | 缓冲区内的商业POI总数 |
| 多样性计算指标 | 香农-威纳指数 (Shannon-Wiener Index) |

商业业态多样性指数计算公式：

**H = - Σ (P_i * ln(P_i))**

其中，P_i 为第 i 种细分业态的 POI 数量占该范围内商业 POI 总数的比例。该指数用于衡量 500 米范围内商业设施的混合度与结构均衡性。
## 3. 公共交通步行接驳分析

### 3.1 数据筛选

使用Python对高德地图采集的CityWalk候选景点进行评分检查、类型筛选和名称去重，并通过AOI空间匹配限定研究范围。最终每个城市选取20个目的地，15个城市共300个景点。高德GCJ-02坐标转换为WGS84，并在距离计算阶段统一转换为对应城市的UTM米制投影坐标系。

### 3.2 关键计算参数

| 参数 | 设置 |
| --- | --- |
| 候选地铁及公交站点范围 | 800米 |
| 附近候选道路 | 10条 |
| 每个位置最多道路接入点 | 3个 |
| 最短路径算法 | Dijkstra |
| 距离计算权重 | 道路长度 |
| 估算步行速度 | 75米/分钟 |

估算总步行距离：

**总距离 = 景点接入距离 + OSM道路最短路径距离 + 站点接入距离**

估算步行时间：

**步行时间（分钟）= 总距离（米）/ 75**

无法获得有效Dijkstra路径时，保留失败状态，不将直线参考距离视为有效步行距离。

城市平均距离只使用成功计算出有效路网路径的景点。

### 3.3 交通与商业匹配标准

结合景点地铁接驳距离与周边500米范围内的商业POI数量进行分析。

交通—商业双优景点需要同时满足：

- 地铁估算步行距离不超过500米。
- 周边500米内商业POI数量不少于47条。

双优景点占比：

**双优景点占比 = 符合条件的景点数量 / 20 × 100%**

无有效地铁路径的景点不计入双优景点，但仍保留在每城20个景点的统计总数中。


## 4. 绿化与综合评价

### 4.1 哪座城市最适合CityWalk？——基准情景下15个新一线城市综合排名
*   **图表说明**：本图展示了基于步行连通性、商业服务、交通接驳与绿化条件四个维度等权重计算下的15个新一线城市CityWalk适宜性综合得分。数据来源为高德POI、OSM路网、公共交通站点及Sentinel-2遥感影像融合后的综合评价结果。
*   **核心结论**：宁波、青岛与重庆的综合得分位列前三，展现出极强的CityWalk优势；东莞、郑州等城市排名相对靠后。这说明排名前列的城市在“路网-商业-交通-绿化”的资源配置上达到了较好的均衡。

### 4.2 偏好改变会导致排名反转吗？——不同游逛偏好下的城市排名变化
*   **图表说明**：本图展示了在基准情景、自然偏好情景（重绿化）与购物偏好情景（重商业）下，15个城市的综合排名变化（纵轴为排名，1代表最优）。
*   **核心结论**：城市排名对权重设置高度敏感，发生了剧烈反转。在自然偏好下，重庆凭借极高的绿化均值跃居第一；而在购物偏好下，青岛凭借密集的商业设施位列榜首。这证明了不存在绝对的“最优CityWalk城市”，推荐结果高度依赖于漫步者的特定偏好。

### 4.3 城市内部存在怎样的空间权衡？——K-Means 聚类中心特征雷达图
*   **图表说明**：本图展示了基于标准化后的四维指标，利用 K-Means 算法对所有城市网格进行无监督聚类后的中心特征。图中三条线分别代表三类典型的空间区域。
*   **核心结论**：聚类成功识别出“交通枢纽型”（交通接驳得分极高）、“商业核心型”（商业与路网密度极高）与“绿地休闲型”（绿化 NDVI 极高）三类区域。雷达图直观呈现了显著的“空间权衡（Spatial Trade-off）”现象，即城市内部极少存在完美的CityWalk空间，各区域往往在“商业便利”与“自然休闲”之间有所侧重。
